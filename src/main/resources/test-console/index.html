민원인과 상담원이 서로 다른 화면(다른 기기)에서 접속해 실제 통화처럼 시험합니다. 민원인의 목소리는 상담원에게 약 0.8초 늦게 들리고, 그 사이 위험한 말은 상담원이 듣기 전에 지울 수 있습니다.

  1. 한 사람은 상담원으로 먼저 접속해 "대기 중"으로 둡니다.
  2. 다른 사람이 민원인으로 전화를 겁니다.
  3. 상담원 화면에 벨이 울리면 받기를 누릅니다. 이제 서로 말할 수 있습니다.
  4. 상담원은 통화 중 위험 구간 차단을 눌러, 방금 민원인이 한 말이 지워지는지 확인합니다.
